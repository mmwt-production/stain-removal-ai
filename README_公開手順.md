# 公開手順

## A. スプレッドシートを保存先にする(1回だけ)

1. https://sheets.new で新しいスプレッドシートを作る(名前は「シミ判定の記録」など)
2. メニュー「拡張機能」→「Apps Script」を開く
3. 最初から入っているコードを全部消し、`sheets_webhook.gs` の中身を貼り付ける
4. 1行目の `CHANGE_ME` を、自分の合言葉に書き換える(例: 決めた文字列)
5. 右上「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
6. 初回は権限の確認が出る → 許可する(「詳細」→「安全ではないページに移動」)
7. 表示された **ウェブアプリのURL**(`https://script.google.com/macros/s/…/exec`)をコピー

## B. Streamlit に設定を渡す

Streamlit Community Cloud のアプリ設定 → 「Secrets」に次を貼る:

```
SHEETS_WEBHOOK_URL = "コピーしたURL"
SHEETS_TOKEN = "手順4で決めた合言葉"
```

※ パソコンで試すときは `.streamlit/secrets.toml.example` を `secrets.toml` にコピーして同じ値を入れる。

## C. 動作確認

判定 → 「記録する」を押して、スプレッドシートの `records` シートに行が増えれば成功。

## 注意

- 保存されるのは回答と判定結果です。**写真は保存されません**(公開版のサーバーは再起動で消えるため)。
- ウェブアプリのURLを知っていて合言葉も合う人だけが書き込めます。URLと合言葉は他人に教えないでください。
- スクリプトを書き換えたら、「デプロイ」→「デプロイを管理」→ 編集 → バージョン「新バージョン」で更新してください。
